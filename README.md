# Isaias Perez — Portfolio

The current portfolio is a fast, accessible React/Vite site focused on forward deployment, AI systems, and software engineering work. It is grounded in the reviewed 2026 résumé and uses direct contact links instead of a transient web form.

## Local development

```bash
npm ci
npm run dev
```

## Verification

```bash
npm run check
npm run build
```

The GitHub Pages workflow publishes the site at `https://ip-04.github.io/isaias-perez/`. The older Render deployment remains separate and unchanged.
